## tramage-atelier

- **Dépôt** : https://github.com/salimadour31-boop/tramage-atelier
- **Démo** : https://salimadour31-boop.github.io/tramage-atelier/
- **Résumé** :
  Générateur de tramage (halftone) classique pour graphistes print, affiche et packaging, 100 % navigateur.
  Motifs points / carrés / lignes / losanges, angle de trame, contraste, duotone, 10 préréglages artistiques.
  Export PNG, SVG vectoriel (Illustrator) et JSON, interface FR/EN/Taqbaylit, licence MIT.

## grain-degrade

- **Dépôt** : https://github.com/salimadour31-boop/grain-degrade
- **Démo** : https://salimadour31-boop.github.io/grain-degrade/
- **Résumé** :
  Générateur de dégradés maillés granuleux (mesh gradient + grain) pour graphistes, dans le navigateur.
  3 à 8 points déplaçables, douceur, ondulation, mélange OKLab, grain procédural, vignette, 10 préréglages, palette aléatoire.
  Export PNG pleine résolution, CSS approché et JSON, graine reproductible, lien partageable, FR/EN/Taqbaylit, MIT.

## lut-atelier

- **Dépôt** : https://github.com/salimadour31-boop/lut-atelier
- **Démo** : https://salimadour31-boop.github.io/lut-atelier/
- **Résumé** :
  Créateur de LUT d'étalonnage cinématique dans le navigateur, pour monteurs et vidéastes.
  Lift/gamma/gain, balance des blancs, virage partiel, fondu film, 12 préréglages, aperçu avant/après et parade RVB.
  Export .cube 17/33/65, PNG et Hald CLUT, import de LUT existantes, FR/EN/Taqbaylit, MIT.
