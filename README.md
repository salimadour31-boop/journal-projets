## duotone-atelier

- **Dépôt** : https://github.com/salimadour31-boop/duotone-atelier
- **Démo** : https://salimadour31-boop.github.io/duotone-atelier/
- **Résumé** :
  Studio duotone gratuit dans le navigateur pour graphistes.
  Ombre + lumière, préréglages, force/luminosité/contraste, export PNG.
  Traitement 100 % local, interface FR/EN/Taqbaylit, licence MIT.

## bpm-atelier

- **Dépôt** : https://github.com/salimadour31-boop/bpm-atelier
- **Démo** : https://salimadour31-boop.github.io/bpm-atelier/
- **Résumé** :
  Tap tempo dans le navigateur pour musiciens et monteurs vidéo, avec métronome.
  Calcule les temps de délai/réverb (notes normales, pointées, triolets) en ms.
  Génère des points de coupe vidéo calés sur le rythme (timecodes, export CSV). FR/EN/Taqbaylit, MIT.

## palette-cinema

- **Dépôt** : https://github.com/salimadour31-boop/palette-cinema
- **Démo** : https://salimadour31-boop.github.io/palette-cinema/ (activer GitHub Pages sur la branche main si besoin)
- **Résumé** : Générateur de palettes cinématiques dans le navigateur. Extraction depuis image/vidéo, préréglages (teal-orange, etc.), export CSS/JSON/PNG. Multilingue FR/EN/Tamazight. 100% local, MIT.

## letterbox-cinema

- **Dépôt** : https://github.com/salimadour31-boop/letterbox-cinema
- **Démo** : https://salimadour31-boop.github.io/letterbox-cinema/ (activer GitHub Pages : Settings > Pages > Branch main / root)
- **Résumé** : Outil navigateur pour letterbox et crop aux ratios cinématiques (2.39:1, 1.85:1...). Import image/vidéo, barres personnalisables, export PNG. Multilingue FR/EN/TZM, traitement local, MIT.

## cadre-cinema

- **Dépôt** : https://github.com/salimadour31-boop/cadre-cinema
- **Démo** : https://salimadour31-boop.github.io/cadre-cinema/ (activer GitHub Pages : Settings > Pages > Branch main / root)
- **Résumé** : Outil navigateur pour appliquer des ratios cinématiques (letterbox ou crop) à des images. Presets Scope/Flat, couleur de barres, export PNG. Multilingue FR/EN/TZM, 100% local, MIT.
