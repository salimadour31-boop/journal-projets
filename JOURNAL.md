# Journal des projets

## palette-cinema — 2026-10-16
- Repo : https://github.com/salimadour31-boop/palette-cinema
- Démo : https://salimadour31-boop.github.io/palette-cinema/
- Outil web gratuit (HTML/CSS/JS, sans installation) qui extrait une palette cinématique (k-means, 5–8 couleurs) d'une image ou d'une image de vidéo.
- Affichage HEX/RGB, copie au clic, export PNG / variables CSS / JSON / texte, et presets « looks de film » originaux.
- Interface responsive et multilingue (français, anglais, taqbaylit), licence MIT.
